# 《周易》语料

正式语料位于仓库根目录 `data/`。每卦一行，按通行卦序排列。文件包含 64 条卦辞、384 条爻辞及乾用九、坤用六，共 450 段经文。解读材料另有 64 段彖传、64 段大象、384 段小象及两处「用」辞的小象。[zhouyi.jsonl](../data/zhouyi.jsonl)

```json
{"number":1,"name":"乾","pattern":"111111","statement":"元亨，利貞。","lines":["潛龍勿用。","見龍在田，利見大人。","君子終日乾乾，夕惕若厲。无咎。","或躍在淵，无咎。","飛龍在天，利見大人。","亢龍，有悔。"],"extra":"見群龍无首，吉。","commentary":{"tuan":"大哉乾元，萬物資始，乃統天。雲行雨施，品物流形。大明終始，六位時成。時乘六龍以御天。乾道變化，各正性命。保合大和，乃利貞。首出庶物，萬國咸寧。","image":"天行健，君子以自強不息。","lines":["潛龍勿用、陽在下也。","見龍在田、德施普也。","終日乾乾、反復道也。","或躍在淵、進无咎也。","飛龍在天、大人造也。","亢龍有悔、盈不可久也。"],"extra":"用九、天德不可為首也。"}}
```

- `number` 和 `name` 是卦号、卦名。`pattern` 的六位从初爻排到上爻，`0` 为阴，`1` 为阳。
- `statement` 是卦辞。`lines` 是初爻至上爻的六条爻辞。`extra` 只出现在乾和坤，分别存放用九与用六。
- `commentary` 包含 `tuan`（彖传）、`image`（大象）和 `lines`（从初爻到上爻的小象）。乾、坤另有 `commentary.extra`。

## 用于占筮

按[动爻取辞规则](divination.md)选经文，再取对应的传文作解读背景。选卦辞时附同卦的彖传和大象。选爻辞时附同卦同爻的小象，可同时提供该卦大象。选用九或用六时附对应的 `commentary.extra`。例如恒卦九二的经文是「悔亡」，对应小象说「能久中也」，给模型提供了具体的解读线索。

这份语料覆盖首版的三钱起卦与取辞。真实模型能否把经传解释准确、联系到用户的问题，仍需在接入后用固定卦例验收。
